# 도막분리_도장

## 결함 개요
- 도막 표면은 남아 있지만 하부층과 분리되어 들뜸 또는 기포처럼 보이는 상태이다.
- 겉보기에는 작아도 내부에는 수분, 염분, 공기가 갇혀 있을 수 있다.
- 넓은 면적의 분리는 부식 진행과 대면적 도막 박리로 이어질 수 있다.
- 두드림 소리, 가장자리 들뜸, 기포 크기를 함께 확인한다.

## 원인
- 표면 수분, 기름, 염분이 제거되지 않은 상태에서 도장한 경우 발생한다.
- 하도와 상도 사이 재도장 간격이 맞지 않아 층간 접착력이 떨어질 수 있다.
- 도막 내부 용제가 충분히 빠지지 않으면 기포와 분리가 생긴다.
- 온도 변화와 결로가 반복되면 도막 아래 수분 압력이 커진다.

## 조치 방법
1. 분리 의심 부위를 눌러 들뜸 범위를 확인하고 경계를 표시한다.
2. 들뜬 도막은 건전한 부착 경계까지 절개하여 완전히 제거한다.
3. 노출면을 세척·건조하고 필요 시 염분 확인 후 표면처리를 수행한다.
4. 규정 도장 시스템으로 재도장하고 각 도장층의 건조 시간을 준수한다.
5. 최종 두께가 80μm 이상인지 측정하고 들뜸 재발 여부를 확인한다.

## 주의사항
- 분리 부위를 바늘로 터뜨리고 덧칠하는 방식은 내부 오염을 제거하지 못한다.
- 비나 결로가 예상되는 시간에는 보수 도장을 진행하지 않는다.
- 도장층 경계는 계단이 생기지 않도록 완만하게 연마한다.
- 분리 면적이 반복적으로 커지면 원인 조사 후 품질 담당자 승인으로 처리한다.
