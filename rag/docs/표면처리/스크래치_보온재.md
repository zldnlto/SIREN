# 스크래치_보온재

## 결함 개요
- 보온재 표면에 긁힘이나 얕은 홈이 생겨 마감층 또는 방습층이 손상된 상태이다.
- 방습층까지 손상되면 수분 유입으로 단열 성능 저하가 발생할 수 있다.
- 작업자 통행부, 공구 보관부, 배관 주변의 좁은 공간에서 자주 확인된다.
- 긁힘 깊이와 방습층 노출 여부를 구분해 기록한다.

## 원인
- 공구, 케이블, 호스가 보온재 표면을 반복적으로 긁어 발생한다.
- 보온재 위에 자재를 올려두거나 이동 장비가 닿으면 흠집이 생긴다.
- 시공 후 보호 커버가 없어 주변 작업 영향으로 손상될 수 있다.
- 칼질 또는 절단 작업 중 마감층을 과도하게 건드린 경우 발생한다.

## 조치 방법
1. 스크래치 부위를 표시하고 방습층 또는 내부 보온재 노출 여부를 확인한다.
2. 표면 마감층만 손상된 경우 지정 보수 테이프나 코팅재로 밀봉한다.
3. 내부 보온재가 노출되었거나 젖은 경우 손상 면적을 확인해 교체 기준과 비교한다.
4. 기준 초과 또는 깊은 손상은 해당 보온재를 절단 제거 후 동일 재질로 교체한다.
5. 마감 후 손으로 눌러 들뜸과 틈이 없는지 확인한다.

## 주의사항
- 보온재 손상은 면적 기준 확인 후 보수 또는 교체를 결정한다.
- 방습층 손상은 작아 보여도 반드시 밀봉해 수분 통로를 차단한다.
- 보수 테이프는 접착면을 건조·청결하게 만든 뒤 붙인다.
- 보온재 표면을 발판이나 작업대로 사용하지 않도록 주변에 안내 표시를 한다.

## 참고 기준
- LNG 탱크 보온재 마감 및 방습층 보수 기준
- 사내 기준: 보온재 손상 시 교체 기준 면적 확인 필요
- 보온재 제조사 보수재 적용 지침
- 선박 단열 시공 외관 검사 기준
