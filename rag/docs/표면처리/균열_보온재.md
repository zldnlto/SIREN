# 균열_보온재

## 결함 개요
- 보온재 표면 또는 단면에 갈라짐이 발생해 단열 연속성이 끊긴 상태이다.
- 균열 부위로 수분이 침투하면 보온 성능 저하와 하부 부식 위험이 커진다.
- 탱크 곡면, 모서리, 고정구 주변, 작업자 접촉이 잦은 위치에서 자주 확인된다.
- 균열 길이, 깊이, 면적, 습윤 여부를 함께 기록한다.

## 원인
- 운반 또는 설치 중 충격으로 보온재가 눌리거나 갈라질 수 있다.
- 곡면부 시공 시 절단 치수나 접착 압착이 맞지 않으면 틈이 발생한다.
- 온도 변화와 반복 진동으로 보온재가 수축·팽창하면서 균열이 생긴다.
- 방습층 손상으로 수분이 들어가면 보온재가 약해져 균열이 확대된다.

## 조치 방법
1. 균열 부위를 표시하고 손상 면적과 주변 방습층 상태를 확인한다.
2. 균열이 작고 건조한 경우 지정 보수재로 틈을 충전하고 표면을 평탄하게 정리한다.
3. 균열이 깊거나 젖어 있거나 면적 기준을 초과하면 해당 구간 보온재를 절단해 제거한다.
4. 동일 규격 보온재로 교체하고 접합부를 밀착시킨 뒤 방습층을 연속되게 복구한다.
5. 복구 후 들뜸, 틈, 수분 잔류 여부를 확인하고 교체 기준 면적 결과를 기록한다.

## 주의사항
- 보온재 손상은 반드시 교체 기준 면적을 확인한 뒤 보수 또는 교체를 결정한다.
- 젖은 보온재를 그대로 덮으면 단열 불량과 부식 위험이 남는다.
- 절단 작업 시 하부 도장면과 케이블, 배관을 손상하지 않도록 보호판을 사용한다.
- 방습층 연결부는 틈 없이 밀봉하고 임시 테이프만으로 완료 처리하지 않는다.

## 참고 기준
- LNG 탱크 보온재 설치 및 보수 작업표준서
- 사내 기준: 보온재 손상 시 교체 기준 면적 확인 필요
- 제조사 보온재 규격서 및 접착제 사용 조건
- 선박 탱크 단열 시공 품질 검사 기준
