# 스크래치_모재

## 결함 개요
- 모재 표면에 긁힘, 홈, 찍힘이 발생해 금속 표면 형상이 손상된 상태이다.
- 얕은 흠집은 표면처리로 복구 가능하지만 깊은 홈은 강도 영향 확인이 필요하다.
- 절단면, 조립 접촉부, 장비 이동 경로, 용접 전 취급 부위에서 자주 발생한다.
- 깊이, 길이, 날카로운 모서리 존재 여부를 측정해 기록한다.

## 원인
- 크레인, 지그, 클램프, 공구가 모재에 직접 닿아 긁힘이 생긴다.
- 부품 적재 시 금속 간 접촉이나 이물 끼임으로 홈이 발생한다.
- 그라인더, 절단기, 드릴 작업 중 주변부를 잘못 건드린 경우 생긴다.
- 보호재 없이 이동하거나 고정하면 반복 마찰로 표면이 손상된다.

## 조치 방법
1. 스크래치 위치와 깊이를 측정하고 구조 중요 부위인지 확인한다.
2. 날카로운 모서리와 버는 연마하여 응력 집중이 생기지 않게 완만하게 만든다.
3. 깊은 홈이나 균열 의심 흔적은 품질 담당자에게 보고하고 필요 시 비파괴 검사를 의뢰한다.
4. 허용 범위 내 손상은 표면을 청소하고 방청 또는 도장 전 표면처리를 수행한다.
5. 보수 후 표면 단차, 잔류 홈, 녹 발생 여부를 재확인한다.

## 주의사항
- 모재를 과도하게 갈아내면 두께 부족이나 형상 불량이 될 수 있다.
- 균열처럼 보이는 흠집은 임의 연마 전에 검사 담당자 확인을 받는다.
- 연마 분진과 날카로운 절삭편에 대비해 보안경과 장갑을 착용한다.
- 도장 예정 부위는 연마 후 오염되지 않도록 즉시 보호한다.
