# 보온재손상_보온재

## 결함 개요
- 보온재가 찢김, 눌림, 파손, 탈락, 젖음 상태로 단열 기능이 저하된 경우이다.
- 손상 부위는 냉열 손실, 결로, 하부 도장면 부식의 시작점이 될 수 있다.
- 작업 통로, 장비 접촉부, 배관·브라켓 주변에서 우선 확인한다.
- 손상 형태, 면적, 깊이, 수분 침투 여부를 구분해 기록한다.

## 원인
- 운반, 적재, 설치 중 충격 또는 압착으로 보온재가 손상될 수 있다.
- 절단 치수 불량이나 접착 부족으로 틈과 들뜸이 발생한다.
- 방습층 파손 후 수분이 침투하면 보온재가 약해지고 기능이 떨어진다.
- 작업자가 보온재를 발판처럼 사용하거나 공구를 기대어 놓는 경우 발생한다.

## 조치 방법
1. 손상 면적과 습윤 여부를 확인하고 교체 기준 면적과 비교한다.
2. 경미한 표면 손상은 지정 보수재로 채우고 표면을 원래 형상에 맞춘다.
3. 깊은 파손, 젖음, 기준 면적 초과 손상은 손상 구간을 절단하여 제거한다.
4. 동일 두께와 재질의 보온재를 끼워 넣고 접합부를 밀착·접착한다.
5. 방습층과 마감재를 복구한 뒤 틈, 들뜸, 수분 잔류 여부를 재검사한다.

## 주의사항
- 보온재 손상 시 교체 기준 면적 확인 없이 임의 보수하지 않는다.
- 젖은 보온재는 건조만으로 합격 처리하지 말고 내부 상태를 확인한다.
- 칼이나 톱 사용 시 하부 도장면, 배관, 케이블을 보호한다.
- 방습층은 겹침 길이와 밀봉 상태를 확인해 수분 통로가 남지 않게 한다.

## 참고 기준
- LNG 탱크 보온재 설치 및 보수 기준
- 사내 기준: 보온재 손상 시 교체 기준 면적 확인 필요
- 보온재 제조사 시공 사양서
- 선박 단열재 외관 및 접합부 검사 기준
