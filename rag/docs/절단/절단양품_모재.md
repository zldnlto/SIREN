# 절단양품_모재

## 결함 개요
- 모재 절단면이 치수 기준을 만족하고 버, 과절단, 깊은 홈이 없는 정상 상태이다.
- 절단면은 조립과 용접에 지장을 주지 않을 만큼 평탄하고 깨끗해야 한다.
- 모서리는 날카로운 위험이 제거되어 후속 작업자가 안전하게 취급할 수 있다.
- 정상 절단면 이미지는 절단불량 오탐 방지 기준으로 사용한다.

## 원인
- 절단 장비 조건, 고정 상태, 절단선 표시가 기준대로 관리된 결과이다.
- 절단 후 버 제거와 표면 청소가 완료된 상태이다.
- 열변형과 치수 편차가 허용 범위 안에 있는 상태이다.
- 검사자가 치수 측정과 외관 확인을 완료한 상태이다.

## 조치 방법
1. 절단 치수, 직각도, 모서리 상태를 측정해 기준 만족 여부를 확인한다.
2. 버와 슬래그가 남아 있지 않은지 손전등과 손 촉감으로 확인한다.
3. 정상 판정 사진과 측정값을 기록해 조립 또는 용접 공정에 인계한다.
4. 양품 절단면은 재오염과 충격을 막기 위해 보호 상태를 유지한다.

## 주의사항
- 버가 작아 보여도 작업자 상해와 조립 간섭을 만들 수 있어 확인한다.
- 절단면이 깨끗해도 치수 미달이면 양품으로 판정하지 않는다.
- 후속 운반 중 절단면이 찍히면 재검사한다.
- 정상 데이터 촬영 시 절단면 전체가 보이도록 각도를 맞춘다.
