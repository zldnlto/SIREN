# 절단불량_보온재

## 결함 개요
- 보온재 절단면이 거칠거나 치수가 맞지 않아 틈, 단차, 눌림이 생긴 상태이다.
- 절단불량은 단열 성능 저하와 방습층 밀봉 불량으로 이어질 수 있다.
- 곡면 탱크부, 배관 관통부, 모서리 마감부에서 자주 확인된다.
- 절단 치수, 틈 폭, 접합부 밀착 상태를 기록한다.

## 원인
- 절단 치수 표시가 부정확하거나 곡면 형상을 반영하지 못한 경우 발생한다.
- 무딘 칼이나 부적절한 공구 사용으로 절단면이 찢기거나 부서진다.
- 보온재를 압착한 상태에서 절단하면 실제 설치 시 틈이 생긴다.
- 관통부와 모서리 템플릿 없이 현장 감으로 절단하면 오차가 커진다.

## 조치 방법
1. 절단부를 맞춰 보고 틈, 단차, 눌림, 방습층 연결 가능 여부를 확인한다.
2. 작은 단차는 평탄하게 다듬고 분진을 제거한다.
3. 틈이 크거나 방습층 밀봉이 어려우면 해당 보온재를 재절단 또는 교체한다.
4. 새 보온재는 템플릿 또는 실측 치수에 맞춰 절단하고 압착 없이 설치한다.
5. 접합부를 밀착시킨 뒤 방습층을 연속되게 마감하고 재검사한다.

## 주의사항
- 큰 틈을 접착제나 테이프만으로 메워 양품 처리하지 않는다.
- 보온재 손상이 동반되면 교체 기준 면적을 확인한다.
- 절단 공구 사용 시 하부 도장면과 손을 보호한다.
- 분진이 접착면에 남으면 접착 불량이 생기므로 마감 전 청소한다.

## 참고 기준
- LNG 탱크 보온재 절단 및 설치 작업표준서
- 보온재 제조사 절단 공구 및 접합부 마감 지침
- 사내 기준: 보온재 손상 시 교체 기준 면적 확인 필요
- 선박 단열재 시공 품질 검사 기준
