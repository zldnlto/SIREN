# 케이블설치양품_케이블그랜드

## 결함 개요
- 케이블그랜드가 케이블 외경에 맞고 패킹, 와셔, 너트가 올바르게 조립된 정상 상태이다.
- 케이블이 흔들리지 않고 외피 눌림이나 방수 틈이 없어야 한다.
- 그랜드와 관통부가 평평하게 밀착되어 수분 유입 가능성이 낮아야 한다.
- 정상 그랜드 이미지는 설치불량 오탐 방지 기준으로 사용한다.

## 원인
- 케이블 외경에 맞는 승인 그랜드를 사용한 결과이다.
- 조립 순서, 패킹 위치, 체결 토크가 제조사 기준대로 적용된 상태이다.
- 관통부 버와 이물이 제거되어 그랜드가 밀착된 상태이다.
- 전기 안전 점검 후 케이블 흔들림과 외피 손상이 없는 상태이다.

## 조치 방법
1. 그랜드 부품 누락, 나사 체결, 패킹 위치를 육안으로 확인한다.
2. 케이블을 가볍게 흔들어 고정 상태를 확인하되 과도하게 당기지 않는다.
3. 외피 눌림, 틈, 수분 흔적이 없으면 정상 사진과 위치를 기록한다.
4. 검사 완료 후 그랜드 주변을 깨끗하게 유지하고 보호 캡 또는 커버를 확인한다.

## 주의사항
- 외관이 정돈되어 보여도 케이블 외경과 그랜드 규격이 맞지 않으면 양품이 아니다.
- 패킹이 비틀리거나 빠져 있으면 방수 기능이 떨어진다.
- 검사 중 케이블을 강하게 당기면 내부 접속부가 손상될 수 있다.
- 정상 데이터는 그랜드 전체와 케이블 입출구가 함께 보이도록 촬영한다.
