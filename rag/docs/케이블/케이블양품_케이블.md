# 케이블양품_케이블

## 결함 개요
- 케이블 외피가 깨끗하고 절상, 눌림, 꺾임, 탄화, 도체 노출이 없는 정상 상태이다.
- 케이블은 기준 경로를 따라 정돈되어 있고 과도한 장력이나 처짐이 없어야 한다.
- 그랜드, 트레이, 바인딩 부위에서도 피복 손상이 없어야 한다.
- 정상 케이블 이미지는 케이블손상 오탐 방지 기준으로 사용한다.

## 원인
- 설치 경로, 보호재, 굴곡반경, 바인딩 조임이 기준대로 관리된 결과이다.
- 날카로운 모서리와 고온부 접촉을 피하도록 배선이 정리된 상태이다.
- 설치 후 전기 기능과 외관 검사가 완료된 상태이다.
- 후속 작업 중 케이블 당김과 압착이 방지된 상태이다.

## 조치 방법
1. 케이블 전체 경로를 따라 외피 손상과 눌림 흔적이 없는지 확인한다.
2. 그랜드 입구와 케이블타이 체결부를 확인해 피복 변형이 없는지 살핀다.
3. 정상 판정 사진, 경로, 태그 정보를 기록한다.
4. 검사 완료 구역은 케이블이 밟히거나 당겨지지 않도록 보호한다.

## 주의사항
- 먼지나 그림자 때문에 손상처럼 보이면 닦고 각도를 바꿔 재확인한다.
- 겉면이 정상이어도 과도한 꺾임이 있으면 내부 손상 가능성을 확인한다.
- 케이블 위에 자재나 공구를 올려두지 않는다.
- 정상 데이터는 케이블 외피와 주변 간섭물이 함께 보이도록 촬영한다.
