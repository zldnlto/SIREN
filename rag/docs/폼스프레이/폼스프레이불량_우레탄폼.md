# 폼스프레이불량_우레탄폼

## 결함 개요
- 우레탄폼 스프레이 두께, 밀착, 표면 균일성, 경화 상태가 기준을 만족하지 못한 상태이다.
- 폼 불량은 단열 성능 저하, 결로, 박리, 빈 공간 발생으로 이어질 수 있다.
- 곡면부, 모서리, 겹침 분사부, 분사 시작·종료 지점에서 자주 확인된다.
- 두께 부족, 과발포, 빈틈, 들뜸, 미경화 여부를 구분해 기록한다.

## 원인
- 원액 배합비, 분사 압력, 노즐 상태, 작업 온도가 기준에서 벗어난 경우 발생한다.
- 분사면에 먼지, 수분, 오일이 있으면 밀착 불량과 박리가 생긴다.
- 한 번에 너무 두껍게 분사하면 내부 미경화나 수축이 발생할 수 있다.
- 작업자 분사 속도와 거리 편차가 크면 두께가 불균일해진다.

## 조치 방법
1. 불량 위치를 표시하고 두께, 밀착, 경화 상태를 확인한다.
2. 미경화, 들뜸, 오염된 폼은 건전한 경계까지 제거한다.
3. 분사면을 청소·건조하고 원액 온도, 압력, 노즐 상태를 재확인한다.
4. 지정 두께가 되도록 얇은 층으로 나누어 재분사한다.
5. 경화 후 두께, 표면 균일성, 빈틈, 들뜸 여부를 재검사한다.

## 주의사항
- 미경화 폼은 피부와 눈에 자극이 있으므로 보호복, 장갑, 보안경을 착용한다.
- 밀폐 공간에서는 환기와 호흡 보호구를 준비한다.
- 젖은 표면에는 폼을 분사하지 않는다.
- 두께 부족 부위를 단순 덧분사할 때는 기존 폼 밀착 상태를 먼저 확인한다.

## 참고 기준
- LNG 탱크 우레탄폼 스프레이 작업표준서
- 우레탄폼 제조사 배합비, 온도, 분사 압력 기준
- 사내 단열 두께 및 밀착 검사 기준
- 선박 단열재 시공 안전 및 환기 기준
