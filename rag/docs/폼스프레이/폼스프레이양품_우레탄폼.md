# 폼스프레이양품_우레탄폼

## 결함 개요
- 우레탄폼이 지정 두께와 형상으로 균일하게 경화되어 표면 결함이 없는 정상 상태이다.
- 폼은 바탕면에 잘 밀착되어 들뜸, 빈틈, 미경화, 과도한 수축이 없어야 한다.
- 곡면과 모서리에서도 두께 편차가 허용 범위 안에 있어야 한다.
- 정상 우레탄폼 이미지는 폼스프레이불량 오탐 방지 기준으로 사용한다.

## 원인
- 원액 배합비, 온도, 압력, 분사 거리와 속도가 기준대로 관리된 결과이다.
- 분사면의 먼지, 수분, 오일이 제거되어 밀착이 확보된 상태이다.
- 층별 분사와 경화 시간이 적절히 지켜진 상태이다.
- 시공 후 두께와 외관 검사가 완료된 상태이다.

## 조치 방법
1. 우레탄폼 표면을 확인해 빈틈, 들뜸, 미경화, 과발포가 없는지 살핀다.
2. 지정 측정 위치에서 두께가 기준을 만족하는지 확인한다.
3. 정상 판정 사진, 두께 측정값, 위치를 기록해 양품 데이터로 저장한다.
4. 검사 완료 후 충격과 오염을 막기 위해 보호 조치를 적용한다.

## 주의사항
- 표면만 평탄해도 내부 빈틈이 의심되면 두께와 밀착 상태를 추가 확인한다.
- 경화 전에는 손으로 누르거나 자재를 기대지 않는다.
- 정상 사진은 표면 질감과 두께 측정 위치가 보이도록 촬영한다.
- 분사 후 냄새나 잔류 가스가 있으면 환기 상태를 유지한다.
